E-Commerce Performance Testing using Apache JMeter
Project Overview:
     1) This project demonstrates Performance Testing skills using Apache JMeter on an E-Commerce Web Application.

     2) The objective is to evaluate application performance under different user loads and identify bottlenecks.

Tools Used :
* Apache JMeter
* Excel
* GitHub
------------------------------------------------------------  
Testing Types Performed :
* Load Testing
* Stress Testing
* Spike Testing
* Endurance Testing
* Volume Testing
-------------------------------------------------------------  
Modules Covered :
* User Login
* Product Search
* Product Details
* Shopping Cart
* Checkout
* Payment
* Order Placement
-------------------------------------------------------------
Test Scenarios :
Test Type	     Users
Load Test	      100
Stress Test	    500
Spike Test	    100 -> 1000
Endurance Test 4 Hours
-------------------------------------------------------------
Metrics Captured :
* Average Response Time
* Throughput
* Error Percentage
* TPS
* 90th Percentile
* 95th Percentile
* CPU Utilization
* Memory Utilization
-------------------------------------------------------------
Key Findings :
* Login module remained stable under 500 users.
* Search API response time increased during stress testing.
* Checkout process met SLA requirements.
